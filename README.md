# ElytraTech

A web-based helmet inventory management system with Point-of-Sale functionality.

## Overview

ElytraTech is a group project built for managing helmet inventory. It supports sales transactions, stock management, and filtering tools to quickly find products.

## Features

- Add, remove, and update helmet records
- Point-of-Sale (POS) for processing sales
- Filter and search inventory
- Stock tracking and management
